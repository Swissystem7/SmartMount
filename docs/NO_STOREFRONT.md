# No storefront — SmartMount

Market verdict is **PARK**. This repo must not sell hardware kits or run a storefront CTA.

## Forbidden

- **Tindie** product / listing CTAs
- **GitHub Sponsors** / Open Collective “support this kit” buttons as a revenue path
- **Kit CTA** copy that invites buyers to order a BOM / maker kit from this project

Research may *mention* third-party boards (Tindie, SparkFun) as competitors or parts sources in `MONETIZATION.md`. That is analysis, not a SmartMount storefront.

## Allowed

- Portfolio / engineering case page honesty: **PARK**, firmware never flashed, **no kit** for sale
- Links to `case/` and docs that restate PARK
