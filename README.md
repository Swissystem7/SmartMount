# SmartMount

> **[לצפייה בדמו החי](https://swissystem7.github.io/SmartMount/)**

SmartMount היא תושבת טלוויזיה חכמה שמזהה סנוור ומכוונת את זווית המסך אוטומטית לצפייה נוחה.

הפרויקט כולל קושחת ESP32, אלגוריתם כיוון לפי חיישני אור ודשבורד ניהול אינטראקטיבי.

להצגה מהירה לשופטים: [HACKATHON.md](HACKATHON.md).
